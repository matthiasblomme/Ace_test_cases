# Per-branch input files

One input file per harness request, named after the harness label, so any branch can
be driven by hand without looking up which base fixture it needs:

```
curl -i -X POST -H "Content-Type: text/xml" --data-binary "@<file>" http://localhost:7801/<url>
```

Generated by `..\..\make-test-data.ps1` - regenerate rather than edit, because four
of these carry a literal `0x1A` byte that editors silently strip or re-encode.

Eleven branches build their test tree inside the flow (a BLOB input feeding a
Compute that overwrites the message), so their request body is ignored - the file
exists so every branch works the same way, marked "ignored" below.

| File | URL | Body | Expected |
|---|---|---|---|
| `A_build.xml` | `/build` | ignored | 500, BIP5004 at `build reply` (write validation catches 0x1A) |
| `B_badschema.xml` | `/badschema` | ignored | 500, BIP5025 at `badschema reply` |
| `C_parse.xml` | `/parse` | **parsed** (0x1A) | 500, BIP5004 at `parse in` (the downstream incident) |
| `D_noval.xml` | `/noval` | ignored | 200, raw `0x1A` byte in the response |
| `E_roundtrip.xml` | `/roundtrip` | **parsed+validated** (clean) | 200, raw `0x1A` in the response (the production scenario) |
| `F_roundtripbad.xml` | `/roundtripbad` | **parsed+validated** (clean) | 200, `<ord:Bogus>` in the response (RCD validated nothing) |
| `G_reparse.xml` | `/reparse` | **parsed** (bogus element) | 500, BIP5025 at the RCD itself (real domain change + Complete) |
| `H_reparse_od.xml` | `/reparseondemand` | **passed through** (bogus element) | 200 (On Demand, nothing touches the tree, no parse) |
| `H2_od_dirty.xml` | `/reparseondemand` | **passed through** (0x1A) | 200, byte intact (proves no parse ran) |
| `I_reparse_tch.xml` | `/reparsetouched` | **partially parsed** (bogus element) | 200 (parse stops at Description, before the violation) |
| `I2_tch_dirty.xml` | `/reparsetouched` | **partially parsed** (0x1A) | 500, BIP5004 at `touch tree (forces parse)` (proves the parse ran) |
| `J_read_bogus.xml` | `/reparsereadbad` | **parsed to the violation** (bogus element) | 500, BIP5025 at `read bogus element` (lazy validation travels) |
| `K_imm_bad.xml` | `/reparseimmediate` | **parsed** (bogus element) | 500, BIP5025 at the RCD (Immediate behaves like Complete) |
| `K2_imm_dirty.xml` | `/reparseimmediate` | **parsed** (0x1A) | 500, BIP5004 at the RCD (proves Immediate parsed at the node) |
| `V1_valnode_1a.xml` | `/validatenode` | ignored | 500, BIP5010+BIP5004 at the Validate node (it serialises internally) |
| `V2_valnode_bad.xml` | `/validatenodebad` | ignored | 500, BIP5010+BIP5026 at the Validate node |

| `W2_blobrnd_bad.xml` | `/rcdblobroundtripbad` | ignored | 500, BIP5009+BIP5025 at the second RCD |
| `X_asbits_1a.xml` | `/asbitstream` | ignored | 500, BIP5010+BIP5004 at the ASBITSTREAM Compute |
| `X2_asbits_bad.xml` | `/asbitstreambad` | ignored | 500, BIP5010+BIP5026 at the ASBITSTREAM Compute |
| `Y_jcn_1a.xml` | `/jcn` | ignored | 500, BIP5010+BIP5004 at the JavaCompute node |
| `Y2_jcn_bad.xml` | `/jcnbad` | ignored | 500, BIP5010+BIP5026 at the JavaCompute node |

BIP fingerprint: schema errors surface as BIP5025 from a parse and BIP5026 from a
write; invalid characters as BIP5004 under BIP5009 (parse side) or BIP5010 (write
side). Full rationale per branch: the project `README.md`.
